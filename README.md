### What is GMM?

Gloss Mod Manager (GMM) is a comprehensive, intelligent game mod manager with built-in AI, MCP, and Skills tools.
It provides an easy-to-use platform to help players download, install, and uninstall mods faster.
Whether you are new to modding or already have an established workflow, GMM brings common tasks together in one place.
It is safe, free of malware, and designed to make mod management straightforward.

### Supported Platforms

- Windows
- macOS
- Linux

### Getting Started

1. Download and install GMM.
2. Launch `Gloss Mod Manager`.
3. Select the game you play.
4. Enjoy!

### Features

- Automatic language selection based on your system language
- Automatic theme selection based on your system theme
- A clean UI without unnecessary content or intrusive ads
- Simple mod installation and downloads
- Convenient mod browsing and downloading
- Smooth animations
- No malware or bundled software
- All features available for free
- Custom tags and categories
- Backups for saves and game files
- Quick switching between games in your library

### From V1 to V2

V2 is a complete upgrade from V1, with a 90% reduction in installer size as its most noticeable improvement.
Another major addition is support for AI, MCP, and Skills tools, enabling GMM to use large language models to manage mod packages and game files more intelligently.
V2 is designed to be compatible with V1 data, including mod lists, game lists, custom games, tag categories, backups, and more.
If you encounter any issues during the upgrade, please report them on [GitHub](https://github.com/GlossMod/Gloss-Mod-Manager/issues).

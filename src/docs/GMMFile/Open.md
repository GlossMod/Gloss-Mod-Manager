# 打开 .gmm 文件

`.gmm` 文件可以通过 Gloss Mod Manager 导入。它可能是 Mod 安装包，也可能是游戏适配文件，导入前请先确认来源可信。

## 导入方式

常见方式有三种：

- 双击 `.gmm` 文件，让系统用 GMM 打开。
- 在 GMM 中使用导入入口选择 `.gmm` 文件。
- 将 `.gmm` 文件拖入对应的游戏或导入区域。

如果双击没有反应，请先启动 GMM，再从界面中手动导入。

## 导入前检查

导入前建议确认：

- 文件来自可信来源。
- 适用游戏与版本匹配。
- 作者说明中没有额外手动步骤。
- 当前游戏目录选择正确。
- 你理解它会安装或修改哪些内容。

## 导入后操作

导入完成后，先查看说明和目标路径，再决定是否启用。对于整合包或带依赖的 `.gmm`，建议按作者推荐顺序启用，并在启用后启动游戏验证。

## 更新与来源

如果 `.gmm` 文件包含来源链接或更新标识，GMM 可以在合适的情况下提示你查看新版本。不同来源的更新能力不同，最终以发布者提供的信息为准。

## 导入失败

如果导入失败，请检查文件是否完整、是否被下载器改名、是否来自早期格式。反馈时请提供 `.gmm` 文件来源、错误截图和 GMM 版本。

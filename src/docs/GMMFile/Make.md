# 制作 .gmm 文件

`.gmm` 文件是 Gloss Mod Manager 用来分享游戏适配、Mod 元数据和安装规则的文件格式。它适合 Mod 作者、整合包维护者和游戏社区把可复用配置打包给其他用户。

## 适合打包什么

你可以用 `.gmm` 分享：

- 单个 Mod 的安装信息。
- 带有前置依赖说明的 Mod 包。
- 某个游戏的适配配置。
- 社区维护的推荐安装规则。
- 标签、说明、来源链接等辅助信息。

## 制作前准备

打包前请确认：

- 目标游戏已经在 GMM 中添加并可以正常管理。
- Mod 已经在本机测试过启用和禁用。
- 元数据包含名称、作者、版本、来源和说明。
- 如果存在依赖，请写清楚依赖关系和安装顺序。

## 推荐流程

1. 在 GMM 中导入并测试目标 Mod 或游戏适配。
2. 补全名称、版本、作者、来源链接和说明。
3. 检查安装类型和目标路径是否正确。
4. 使用打包功能导出 `.gmm` 文件。
5. 在干净环境重新导入，验证它能被其他用户正常使用。

## 打包内容

`.gmm` 文件可能包含：

- Mod 或适配的基础信息。
- 安装、卸载和识别规则。
- 来源链接、更新标识和版本信息。
- 标签、分类和可读说明。
- 必要的文件清单或配置文件。

请不要打包账号信息、私人存档、商业素材或未经授权的文件。

## 分享建议

发布 `.gmm` 时建议同时提供：

- 适用游戏和版本。
- 支持的 GMM 版本。
- 安装前置要求。
- 已知冲突。
- 问题反馈入口。

如果 `.gmm` 来自社区维护，请保留原作者和来源链接，方便用户追踪更新。

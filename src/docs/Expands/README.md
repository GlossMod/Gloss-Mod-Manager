# 游戏适配

Gloss Mod Manager V2 支持通过内置适配、社区 `.gmm` 文件和自定义配置来管理不同游戏。适配的目标不是把所有游戏都写成固定逻辑，而是描述“如何识别游戏、如何识别 Mod、如何安装和卸载文件”。

## 推荐方式

优先级建议如下：

1. 使用 GMM 已内置支持的游戏。
2. 导入社区维护的 `.gmm` 适配文件。
3. 使用界面中的自定义游戏流程创建配置。
4. 对复杂游戏再编写 JSON 或 TypeScript 适配。

如果你只是想让一个游戏可以复制类 Mod，通常 JSON 适配已经足够。只有需要复杂判断、动态路径或特殊安装逻辑时，才建议使用 TypeScript。

## 适配需要描述什么

一个完整适配通常包含：

- 游戏标识和显示名称。
- 游戏目录识别规则。
- 启动程序或启动方式。
- 支持的 Mod 类型。
- 每种类型的安装和卸载规则。
- Mod 类型检查规则。
- 可选的下载源、封面和社区链接。

## 分享前检查

分享适配前请至少完成这些验证：

- 在干净游戏目录中导入并启用测试 Mod。
- 禁用后确认文件可以恢复或清理。
- 检查错误目录、空目录和重复文件的处理。
- 确认 `.gmm` 文件中的描述足够让用户理解用途。

## 参与维护

如果你希望长期维护某个游戏适配，请在反馈渠道说明游戏、平台、可测试版本和计划支持的 Mod 类型。稳定适配会优先整理进官网文档或推荐列表。

# 安装与卸载 Mod

V2 的 Mod 操作尽量围绕“可追踪、可撤销、少打扰游戏原文件”设计。不同游戏的实际安装策略可能不同，但界面中的启用、禁用和卸载含义保持一致。

## 安装前检查

安装 Mod 前请确认：

- 游戏目录选择正确，并且当前用户有写入权限。
- Mod 文件来自可信来源，压缩包可以正常解压。
- Mod 适用于当前游戏版本。
- 如果 Mod 需要前置组件，已经先安装对应前置。

## 导入 Mod

在游戏详情页点击导入按钮，选择压缩包、文件夹或 `.gmm` 文件。GMM 会读取文件结构，并根据当前游戏适配规则判断目标路径。

导入完成后，Mod 会先进入列表。此时它不一定已经影响游戏目录，只有启用后才会应用。

## 启用 Mod

启用时，GMM 会根据游戏配置执行复制、链接、替换或其他适配动作。对于可能覆盖原文件的操作，V2 会尽量保留可恢复信息。

启用后建议立即启动游戏验证一次，尤其是以下情况：

- Mod 修改启动器、脚本或核心资源文件。
- 多个 Mod 修改同一文件。
- Mod 说明中要求固定加载顺序。

## 禁用与卸载

禁用表示暂时撤销 Mod 效果，但保留它在 GMM 中的记录。卸载表示移除这个 Mod 的管理记录，并按提示清理相关文件。

如果你只是在排查问题，优先使用禁用；确认不再需要时再卸载。

## 处理冲突

当多个 Mod 修改同一目标时，可能出现覆盖或不兼容。建议按下面顺序排查：

1. 只启用最基础的前置 Mod。
2. 逐个启用功能 Mod，并每次启动游戏验证。
3. 发现问题后查看最近启用的 Mod 和日志。
4. 查阅游戏社区是否有兼容补丁或推荐排序。

## 手动修改注意事项

如果你在 GMM 外手动改动了游戏文件，GMM 可能无法完整识别这些变化。排查问题时请说明是否做过手动覆盖、手动删除或使用过其他管理器。

# 移动数据目录

如果默认数据目录空间不足，可以在 V2 设置中调整保存位置。移动前请先关闭 GMM，避免正在写入的文件被复制到一半。

## 推荐流程

1. 关闭 GMM。
2. 在新磁盘创建一个用于保存 GMM 数据的目录。
3. 将旧数据目录中的内容完整复制到新目录。
4. 启动 GMM，在设置中把保存位置切换到新目录。
5. 重启 GMM，检查游戏和 Mod 列表是否正常。

## 注意事项

- 不要只移动其中一部分文件。
- 不建议放在 OneDrive、网盘同步目录或权限受限目录中。
- 新目录路径尽量简短，避免特殊字符。
- 移动后先不要立刻删除旧目录，确认无误后再清理。

## 列表丢失怎么办

如果移动后游戏或 Mod 列表为空，请先切回旧目录确认数据仍在，再检查新目录是否复制完整。反馈时请提供旧目录、新目录和错误截图。

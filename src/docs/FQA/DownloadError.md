# 下载失败或一直等待

下载失败通常与网络连接、下载目录权限、代理、防火墙或第三方下载器冲突有关。

## 先检查这些内容

- 当前网络可以访问对应下载源。
- 下载目录有足够空间，并且当前用户可写入。
- 防火墙允许 GMM 访问网络。
- 没有其他下载器占用相同端口或拦截链接。
- 代理设置与系统网络设置一致。

## 一直处于等待状态

如果任务长时间没有进度，可以尝试：

1. 暂停任务后重新开始。
2. 重启 GMM。
3. 更换下载源或手动下载 Mod。
4. 清理下载目录中的临时文件。
5. 检查是否有下载器、代理或安全软件冲突。

## 写入文件失败

写入失败一般是权限或文件占用问题。请关闭正在使用目标文件的程序，确认目录可写，再重新下载。

如果下载目录位于系统盘、同步盘或带权限限制的目录，建议在设置中换到一个普通用户目录。

## 反馈时请提供

- 失败的下载链接或 Mod 名称。
- 下载源名称。
- 错误提示截图。
- GMM 版本和系统版本。
- 是否使用代理、加速器或第三方下载器。

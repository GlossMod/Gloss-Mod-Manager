# GMM 无法启动

如果 Gloss Mod Manager V2 无法打开、启动后立刻退出或没有任何窗口，通常与系统环境、权限、图形驱动或安全软件拦截有关。

## 先确认环境

- 使用 Windows 10 或更新系统。
- 使用 64 位系统。
- 从官方渠道下载最新稳定版。
- 安装目录不要放在需要额外权限的系统目录中。

## 常见处理方式

可以按顺序尝试：

1. 更新显卡驱动。
2. 右键以管理员身份运行一次。
3. 将 GMM 移到默认安装目录或纯英文路径目录。
4. 暂时关闭安全软件拦截后重新启动。
5. 重新安装最新版本。

## 收集错误信息

如果仍然无法启动，请提供以下信息：

- GMM 版本号。
- 系统版本。
- 安装目录。
- 启动时的报错截图。
- 日志文件或命令行输出。

你可以在终端中运行 GMM 主程序，复制控制台输出一起反馈。路径中有空格时，请用英文双引号包住完整路径。

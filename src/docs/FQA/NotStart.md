# 启用 Mod 后游戏无法启动

如果游戏在启用 Mod 后闪退、黑屏或无响应，通常是 Mod 不兼容、前置缺失、加载顺序错误或游戏版本不匹配。

## 快速排查

1. 禁用最近启用的 Mod。
2. 只保留必要前置，启动游戏测试。
3. 确认 Mod 支持当前游戏版本。
4. 检查是否缺少运行库、脚本框架或插件前置。
5. 查看游戏社区推荐的加载顺序。

## 逐个定位

如果你一次安装了很多 Mod，请先全部禁用，然后每次只启用一个或一组相关 Mod。每次变更后启动游戏验证，直到找到触发问题的 Mod。

## 可能不是 GMM 问题

GMM 负责把文件按规则安装到目标位置，但游戏是否能加载这些文件取决于游戏、Mod 和前置环境。如果同一个 Mod 手动安装也会导致闪退，应优先联系 Mod 作者或查看该 Mod 的说明。

## 反馈时请提供

- 游戏名称和版本。
- 启用的 Mod 列表。
- 最近启用或更新的 Mod。
- 游戏报错截图或日志。
- GMM 的操作日志。

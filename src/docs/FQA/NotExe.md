# 选择游戏目录

添加游戏时，V2 会尽量根据适配规则判断你选择的目录是否正确。大多数情况下，你应该选择游戏根目录，而不是随意选择某个子文件夹。

## 选择目录还是程序

不同游戏的规则不同：

- 普通桌面游戏通常选择游戏根目录或主程序所在目录。
- Steam 游戏可以优先通过 Steam 目录自动识别。
- Microsoft Store 或 Xbox 游戏可能需要选择目录，并处理权限限制。
- 部分游戏主程序不在根目录，需要按照适配说明选择。

如果界面提示“没有找到主程序”或“目录不匹配”，请回到游戏安装目录重新选择。

## 找不到 EXE

找不到主程序时可以检查：

- 游戏是否完整安装。
- 选择的是否是启动器目录，而不是游戏实际目录。
- 游戏是否来自 Microsoft Store 并受到权限保护。
- 杀毒软件是否隔离了主程序。

## 仍然无法添加

请反馈游戏名称、游戏平台、你选择的目录截图，以及该目录下的文件结构截图。社区维护者可以据此修正游戏适配规则。

# Mod 类型未知

当 GMM 无法根据文件结构判断 Mod 类型时，会显示未知类型或要求你手动选择。这个问题通常来自压缩包结构不标准、游戏适配规则不足或 Mod 使用了新的安装方式。

## 可以先这样处理

1. 打开压缩包查看第一层目录。
2. 对照 Mod 作者的安装说明确认目标路径。
3. 在 GMM 中手动选择最接近的类型。
4. 启用前确认文件会被安装到正确位置。

## 什么时候需要反馈

如果同一个游戏的大量 Mod 都无法识别，可能是游戏适配规则需要更新。请提交：

- 游戏名称。
- Mod 下载链接或文件结构截图。
- 作者说明中的安装路径。
- GMM 显示的类型判断结果。

## 为社区完善规则

你也可以通过 [合作与共建](../Cooperation.md) 参与适配规则维护。稳定的识别规则可以减少其他用户手动选择的成本。

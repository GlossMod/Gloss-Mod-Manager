# Mod 没有效果

Mod 显示已启用但游戏内没有效果，通常是安装类型识别错误、目标路径不匹配、前置缺失或游戏版本不兼容。

## 检查安装状态

- 确认 Mod 在当前游戏下已启用。
- 检查是否启用了正确的 Mod 类型。
- 查看目标游戏目录中是否出现了预期文件。
- 确认游戏启动的是同一个安装目录。

## 检查 Mod 说明

有些 Mod 需要额外步骤，例如：

- 安装脚本框架或加载器。
- 修改配置文件。
- 在游戏内启用某个选项。
- 使用指定启动参数。

请优先阅读 Mod 作者提供的说明。

## 路径不匹配

如果 Mod 压缩包内部多了一层目录，或者文件结构与适配规则不一致，GMM 可能无法把文件放到预期位置。可以重新打包 Mod，或反馈给适配维护者完善识别规则。

## 反馈时请提供

- Mod 压缩包内部结构截图。
- GMM 中选择的 Mod 类型。
- 游戏目录中实际生成的文件路径。
- Mod 作者的安装说明链接。

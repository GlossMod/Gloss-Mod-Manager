# 从 V1 升级到 V2

如果您是V1版本的用户，想要升级到V2版本，请按照以下步骤操作：
- 备份您的 `Documents\Gloss Mod Manager` 文件夹，以防止数据丢失。
- 备份您的 `mods` 文件夹( 如果有额外设置的话) ;
- 需要先卸载 V1 版本, 卸载后请务必重启电脑, 以确保所有相关文件被正确删除;
- 从 [下载](/download) 页面下载最新的 v2 版本
- 安装， 正常情况会自动识别旧的数据并进行兼容
- 如果您之前手动改过存储路径，则在设置里面重新设置一下存储路径即可
- 如有问题，欢迎在 [GitHub Issues](https://github.com/GlossMod/Gloss-Mod-Manager/issues) 提交反馈

# 更新渠道

Gloss Mod Manager V2 会根据安装来源采用不同的更新方式。你不需要手动修改更新配置，只需要从原安装渠道获取更新即可。

## GitHub Releases 版本

如果你从 GitHub Releases 下载 V2，推荐继续从 Releases 获取更新。这个渠道适合希望第一时间查看更新日志、下载便携包或安装包的用户。

## Microsoft Store 版本

如果你从 Microsoft Store 安装，更新由商店处理。GMM 不会绕过商店直接替换应用文件。请在 Microsoft Store 中检查更新，或开启系统的应用自动更新。

## 社区镜像版本

社区镜像适合访问 GitHub 不稳定的用户。使用镜像时请确认发布者可信，并核对版本号、发布时间和文件完整性。

## 选择哪个渠道

- 想要自动更新：优先使用 Microsoft Store。
- 想要最新版本和完整更新日志：优先使用 GitHub Releases。
- 网络访问受限：使用可信社区镜像。

不同渠道的更新节奏可能略有差异。遇到问题时，请在反馈中说明你的安装来源。

## 更新前建议

更新前请关闭正在运行的游戏和 GMM。更新后如果发现异常，可以先重启系统，再检查数据目录和游戏配置是否正常。

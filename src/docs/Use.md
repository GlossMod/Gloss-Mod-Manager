# 开始使用

Gloss Mod Manager V2 的主线流程是：先管理游戏，再管理这个游戏下的 Mod。你不需要记住复杂目录，只需要确认游戏位置、导入 Mod，然后通过开关控制启用状态。

## 首次启动

首次启动后，建议先完成这几项设置：

1. 确认程序显示语言和外观模式。
2. 选择用于保存 GMM 数据、缓存和备份的位置。
3. 检查下载目录和临时目录是否有足够空间。
4. 如果你会使用 AI 辅助配置，可以阅读 [MCP 与 AI 助手](MCP.md)。

## 添加游戏

你可以通过以下方式添加游戏：

- 从已支持游戏列表中选择，并指定游戏安装目录。
- 打开社区提供的 `.gmm` 文件导入游戏适配信息。
- 按文档手动创建适配配置，再保存为自己的游戏条目。

添加完成后，GMM 会为该游戏建立独立的 Mod 列表、启用状态和必要的备份记录。

## 导入 Mod

V2 支持常见的 Mod 来源：

- 压缩包：例如 `.zip`、`.7z`、`.rar`。
- 文件夹：适合已经解压或正在开发的 Mod。
- `.gmm` 文件：适合社区打包的游戏或 Mod 配置。

导入后请先查看 Mod 的说明、目标路径和依赖信息，再启用它。对于会覆盖游戏原文件的 Mod，建议先确认 GMM 已经创建备份。

## 管理 Mod 状态

每个 Mod 都可以单独启用或禁用。常见操作包括：

- 启用：将 Mod 内容应用到目标游戏目录。
- 禁用：撤销 Mod 对游戏目录的影响。
- 排序：当多个 Mod 修改同一类文件时，后应用的规则可能覆盖前一个。
- 卸载：移除 GMM 中的 Mod 记录，并按提示清理文件。

如果某个游戏有特殊加载顺序，请优先遵循对应游戏页面或社区说明。

## 使用建议

- 每次大量调整 Mod 前，先确认游戏可以正常启动。
- 不要同时用多个 Mod 管理器改同一个游戏目录。
- 遇到冲突时，先禁用最近启用的 Mod，再逐个排查。
- 分享问题时附上游戏名称、GMM 版本、Mod 名称和日志截图。

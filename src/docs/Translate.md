# 翻译与本地化

Gloss Mod Manager V2 的界面和文档会优先维护中文版本，随后逐步开放其他语言。你可以参与术语校对、界面翻译、文档翻译和游戏适配说明翻译。

## 翻译范围

当前可参与的内容包括：

- 应用界面文本。
- 错误提示和操作说明。
- 官网与文档内容。
- 游戏适配说明和 `.gmm` 元数据。

## 术语原则

为了减少用户理解成本，建议遵循这些原则：

- 同一个概念使用同一个译名，例如“启用”“禁用”“卸载”不要混用。
- 优先使用玩家熟悉的表达，不为了直译牺牲可读性。
- 保留必要的英文专有名词，例如 Mod、MCP、Skills、Release。
- 文档语言尽量短句、明确、可操作。

## 参与方式

你可以通过 GitHub Pull Request 提交翻译，也可以在反馈渠道中提交术语建议。提交时请说明：

- 你修改的是界面、文档还是游戏适配说明。
- 原文和建议译文分别是什么。
- 是否有上下文截图。

## 英文版本计划

当前官网暂时不展示英文文档。等 V2 中文文档稳定后，再统一整理英文版本，避免多个语言版本长期不一致。

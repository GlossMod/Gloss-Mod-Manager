# 反馈问题

如果你在 V2 中遇到安装失败、游戏无法启动、Mod 状态异常或界面错误，请尽量提交可复现的信息。信息越完整，维护者越容易判断是 GMM 问题、游戏适配问题还是 Mod 本身问题。

## 反馈前先检查

提交问题前建议先确认：

- 使用的是最新稳定版 GMM。
- 游戏本体可以在不启用 Mod 的情况下正常启动。
- Mod 适用于当前游戏版本。
- 没有同时使用其他 Mod 管理器修改同一目录。
- 已经查看过 [常见问题](FQA/CantStart.md)。

## 请提供的信息

反馈时请尽量包含：

- GMM 版本号和系统版本。
- 游戏名称、游戏平台和游戏版本。
- 出问题的 Mod 名称、来源和版本。
- 你执行的具体步骤。
- 期望结果和实际结果。
- 错误截图、日志或可复现的最小文件结构。

## 问题类型

常见问题可以按以下方式描述：

- 安装失败：导入、解压、复制或权限相关问题。
- 启动失败：启用 Mod 后游戏无法启动或闪退。
- 状态异常：界面显示已启用，但游戏内没有效果。
- 适配错误：目标路径、规则或 `.gmm` 配置不正确。
- 界面问题：按钮、布局、语言或显示异常。

## 提交渠道

推荐通过 GitHub Issues 提交可追踪的问题。社区讨论、即时消息和评论区适合快速沟通，但不适合沉淀复杂问题。

提交后如有补充信息，请继续更新同一个问题，不要重复开多个相同主题。

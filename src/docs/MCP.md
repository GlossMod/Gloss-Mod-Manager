# MCP 与 AI 助手

Gloss Mod Manager V2 提供面向 AI 工具的 MCP 能力。启用后，支持 MCP 的编辑器或助手可以在你的授权下读取必要上下文，帮助分析游戏目录、理解 Mod 结构、生成适配配置或排查常见错误。

## 适合做什么

MCP 适合处理这些任务：

- 根据游戏目录结构生成 `.gmm` 适配草稿。
- 分析 Mod 压缩包内的路径是否匹配目标游戏。
- 检查常见冲突，例如重复覆盖同一文件。
- 生成反馈问题时需要的环境信息清单。
- 为社区维护者整理游戏适配文档。

## 使用前提

你需要准备：

- 已安装 Gloss Mod Manager V2。
- 一个支持 MCP 的 AI 客户端或编辑器。
- 对本机文件访问权限有清晰理解，只授权你信任的工具。

MCP 不是云端自动托管能力。它运行在你的本地环境中，访问范围取决于你给客户端的配置和授权。

## 建议流程

1. 在 GMM 中确认目标游戏已经添加。
2. 在 AI 客户端中配置 GMM 的 MCP 服务。
3. 让 AI 只读取当前游戏和当前 Mod 相关目录。
4. 先生成配置草稿，再人工检查路径、规则和说明。
5. 测试通过后再分享给其他用户。

## 安全建议

- 不要把包含账号、存档隐私或商业文件的目录暴露给不可信客户端。
- 不要直接执行 AI 生成的批量删除、覆盖或移动命令。
- 生成 `.gmm` 配置后，先在测试目录验证。
- 分享日志前检查是否包含用户名、完整路径或令牌。

## 与 Skills 的关系

Skills 更偏向固定任务模板，适合把常见的游戏适配、排查步骤和社区规范沉淀下来。MCP 提供本地上下文，Skills 提供工作方法，两者配合可以让 AI 辅助更稳定。

# 合作与共建

Gloss Mod Manager V2 希望成为游戏社区、Mod 作者和工具维护者都能参与的开放工具。无论你维护的是游戏适配、Mod 合集、内容平台还是教程站点，都可以围绕 `.gmm`、文档和自动化能力共建生态。

## 适合合作的方向

- 游戏社区：维护某个游戏的适配规则、推荐安装流程和常见问题。
- Mod 作者：为自己的 Mod 提供标准化元数据和安装说明。
- 内容平台：提供稳定的下载、版本说明和跳转入口。
- 工具作者：围绕 GMM 的配置、MCP 或自动化流程做扩展。
- 翻译贡献者：帮助维护多语言界面和文档。

## `.gmm` 生态

`.gmm` 文件可以承载游戏或 Mod 的适配信息，让用户少做手动路径判断。维护良好的 `.gmm` 文件应该包含清晰的名称、版本、目标游戏、安装规则和说明。

分享前请先在干净环境测试，确保用户导入后能理解它会修改哪些内容。

## 文档共建

官网文档以 Markdown 管理。适配文档应尽量包含：

- 游戏版本和平台说明。
- 支持的 Mod 类型。
- 安装、启用、禁用和卸载注意事项。
- 常见冲突和排查步骤。

## 联系与流程

如果你希望长期维护某个游戏或接入社区资源，建议先提交 Issue 说明目标、资源范围和维护计划。成熟内容可以通过 Pull Request 合并到官网文档或适配仓库中。
